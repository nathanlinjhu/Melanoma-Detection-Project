# Melanoma Detection Using Deep Learning

A deep learning project exploring skin-lesion image classification for melanoma detection using a ResNet50-based model. Developed at Johns Hopkins University from September to December 2025.

## Overview

This project applies computer vision to biomedical images, with a focus on classification performance and training efficiency. The model was developed using a dataset of 900 images and achieved 97.3% validation accuracy.

## Key Results

| Metric | Result |
| --- | --- |
| Model architecture | ResNet50-based model |
| Dataset size | 900 images |
| Validation accuracy | 97.3% |
| Training-time reduction | 3 hours compared with the initial implementation |

## Project Focus

- Apply deep learning to skin-lesion image classification.
- Evaluate model performance on validation data.
- Optimize the model's training process to improve efficiency.

## Results and Limitations

The reported 97.3% accuracy reflects performance on the project's validation data. It does not establish performance on an independent clinical dataset or demonstrate readiness for clinical use.

Further evaluation could include precision, recall, F1 score, a confusion matrix, and testing on a larger, more diverse independent dataset.

## Future Improvements

- Document the dataset source, class distribution, and training/validation split.
- Compare performance with additional model architectures.
- Examine misclassified images to understand model limitations.
- Add reproducible setup, training, and evaluation instructions.
